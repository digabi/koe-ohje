Accessibility Statement, Instructions for the Abitti Test Environment

The test environment instructions are part of the Abitti test software. This statement describes any shortcomings in the accessibility of the instructions and explains how you can provide feedback to the Matriculation Examination Board regarding the accessibility of the instructions.

Accessibility of the Instructions

The instructions largely meet the legally required accessibility criteria at levels A and AA (WCAG 2.1), and there are no critical accessibility deficiencies in the instructions. The conventions used in the instructions (including keyboard shortcuts) are described later in this statement.

Navigation in the Instructions

The instructions consist of tabs, the navigation for which is located at the beginning of the page. You can move to the tab navigation by pressing Alt+T (tabs).

All tabs contain a table of contents listing H1, H2 and H3 level headings. In shorter tabs, the table of contents may be empty. You can move to the table of contents by pressing Alt+M (menu).

All tabs contain a search function that searches for results within the currently active tab. Search results are updated as you type the search term. The results are displayed below the search field. You can move to the search field by pressing Alt+S (search).

The Programming tab consists of background material and a Python editor. You can move to the Python editor by pressing Alt+E (editor). To leave the editor, press Alt+R (run), which moves the focus to the program's run button. The program output is displayed below the run button. You can move the focus to the program code copy button by pressing Alt+C (copy).

Mathematical Formulae

Mathematical formulae are read in LaTeX format. When the focus is on a formula, the LaTeX code of the formula or mathematical notation can be copied to the clipboard by pressing Enter.

Did You Notice Accessibility Issues?

We continuously strive to improve the accessibility of the instructions. If you encounter problems on the website that are not described in this statement, please notify us. We also welcome other observations and suggestions for improving the accessibility of the instructions. Send your feedback by email to Abitti support at abitti@ylioppilastutkinto.fi.

Supervisory Authority

If you notice accessibility issues on the website, please first provide feedback to us, the website administrator. It may take up to 14 days to receive a response. If you are not satisfied with the response you receive, or if you do not receive a response within two weeks, you may submit a report to the Regional State Administrative Agency for Southern Finland. The website of the Regional State Administrative Agency for Southern Finland provides detailed information on how to submit a report and how the matter will be processed.
