if-else

If-else-rakenteessa suoritetaan aina jompikumpi vaihtoehtoisista lohkoista. if-lohko suoritetaan vain jos ehto on tosi ja kaikissa muissa tapauksissa suoritetaan else-lohko.

I if-else-strukturen körs alltid något av de alternativa blocken. Blocket if körs endast om villkoret är sant, och i alla andra fall körs blocket else.

In an if-else structure, one of the two alternative blocks is always executed. The if block is executed only if the condition is true, and in all other cases the else block is executed. 

number = 5

if number % 2 == 0:
  print("Your number is even.")
else:
  print("Your number is odd.")

Your number is odd.

if-elif-else

Usein vertailussa vaihtoehtoja saattaa olla enemmän kuin kaksi, kuten esimerkiksi suurempi, yhtäsuuri tai pienempi. elif-haara on vaihtoehtona alkuperäiselle if-ehdolle. elif-haaroja voi olla useampi ja niistä suoritetaan ensimmäinen, jonka arvo on tosi.

Ofta i en jämförelse kan det finnas fler än två alternativ, till exempel större, lika eller mindre. elif-grenen är ett alternativ till det ursprungliga if-villkoret. Det kan finnas mer än en elif-gren, och den första som är sann körs.

In many comparisons, there may be more than two alternatives, such as greater than, equal to, or less than. The elif branch is an alternative to the original if condition. There can be multiple elif branches, and the first one that evaluates to true is executed. 

number = 30

if number == 0:
  print("Your number is zero.")

elif number < 0:
  print("Your number is negative.")

else:
  print("Your number is positive.")

Your number is positive.
